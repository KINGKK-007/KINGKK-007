Typography uses Manrope and JetBrains Mono from Google Fonts, pinned to commit `2eb0b48d5f760f62e286216f0859a8c540dbc1bd`.

- [Manrope source](https://github.com/google/fonts/tree/2eb0b48d5f760f62e286216f0859a8c540dbc1bd/ofl/manrope)
- [JetBrains Mono source](https://github.com/google/fonts/tree/2eb0b48d5f760f62e286216f0859a8c540dbc1bd/ofl/jetbrainsmono)

Each font includes its original SIL Open Font License. The bundled, unmodified font files are used by `scripts/typography.py` to render self-contained SVG outlines.
